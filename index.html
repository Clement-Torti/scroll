Shorts FR

Un feed infini de Shorts,
uniquement en français.

Découverte automatique via l'API YouTube, filtre de langue en 5 couches, et tes chaînes préférées suivies pour ne rien manquer.

Clé API YouTube Data v3

La clé reste dans le localStorage de ce navigateur. Elle n'est envoyée qu'à googleapis.com.

Obtenir une clé (2 min, gratuit)

  1. Crée un projet sur Google Cloud.
  2. Active YouTube Data API v3.
  3. Identifiants → Créer → Clé API.
  4. Restreins-la : Sites web → ton domaine *.github.io/*, et API → YouTube Data API v3.

Quota gratuit : 10 000 unités/jour. L'app est optimisée pour en consommer le moins possible (voir « Quota » dans les réglages).

Profil dans une Google Sheet — facultatif

Sans ça l'application fonctionne, mais le profil (chaînes découvertes, abonnements, thèmes) ne vit que dans ce navigateur.

Renseigné ici plutôt que dans les réglages, le profil est chargé avant la première recharge : sur un nouvel appareil le feed démarre sur tes chaînes déjà connues, pour environ 2 unités au lieu d'une recherche à 100.
